# Cunga Logo Assets

## Logo Files Needed

Please save your logo files to this directory:

### Required Files:
1. **logo-full.svg** - Full logo with text (Primary)
2. **logo-icon.svg** - Icon only (for small spaces)
3. **logo-wordmark.svg** - Wordmark only (text without icon)
4. **logo-dark.svg** - Logo for dark backgrounds
5. **logo-light.svg** - Logo for light backgrounds
6. **logo-with-tagline.svg** - Logo + "Grow Your Business, Simply."

### File Formats:
- **SVG** (preferred - scalable, crisp at any size)
- PNG (fallback - save at 2x resolution for retina displays)
  - logo-full@2x.png (recommended: 400x120px)
  - logo-icon@2x.png (recommended: 120x120px)

## Typography
- **Headings & Display:** Poppins (600, 700, 800)
- **Body & UI:** Inter (400, 500, 600)

## Usage Guidelines

1. Use **logo-full.svg** in the navbar (desktop)
2. Use **logo-icon.svg** in the navbar (mobile)
3. Use **logo-dark.svg** on dark backgrounds
4. Use **logo-with-tagline.svg** on landing/auth pages
5. Maintain minimum clear space around logo (equal to the height of the 'C')
6. Don't stretch or distort the logo
7. Don't change the gradient colors
